## 5. 已知限制

1. **图片是自制 SVG 示意图**，不是真实生成；每镜头构图不同，但没有真实风格/角色一致性识别。
2. **镜头排序**提供上移/下移（键盘可用），同 Beat 重排序会创建新 SB/Shot 草稿；跨 Beat 拒绝，未实现拖拽。
3. **AI 导演为规则映射**：覆盖动作/时长/文本/角色/画幅等常见意图，未知话术只生成保守计划，不调用真实模型。
4. **版本冲突**：概念/剧本/镜头已提供三选差异面板（保留我的编辑/查看最新/另存新草稿），但尚未写双标签页浏览器自动化用例。
5. **刷新任务恢复**：jobId 已写入 URL，刷新后继续轮询；但页面首次加载仍先渲染旧数据，任务进度出现有短暂延迟，未做全页面骨架占位。
6. **失效传播**：服务端会传播 STALE，动画页提供“查看影响详情”抽屉（可定位阶段与对象）与旧快照只读；暂无逐镜头图形化依赖图。
7. **Reviewer 审核**：按钮按 `reviewerCanApprove` 控制，API 403 校验；未做完整浏览器用例（API editor 403 已覆盖）。
8. **M2 不做**：真实 TTS/音频、视频生成、积分、FFmpeg、多轨剪辑、多人实时协同。
9. **动画/无障碍**：未实现 `prefers-reduced-motion` 降级和完整键盘播放器操作。
