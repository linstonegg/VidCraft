## 5. 已知限制与未完成项（如实说明）

1. **上传只保存元数据**：不做真实文件存储/OCR/STT/PDF 解析；刷新后 blob 预览失效，页面提示重新选择；这是 M1 文档允许的方案。
2. **演示授权只做弹窗与状态摘要**：未实现“登录页→仪表盘→功能树”的逐节点 mock 探索树；`DemoSessionSummary` 与状态机已具备。
3. **任务取消仅 API**：`POST /jobs/:id/cancel` 已实现，页面未放入取消按钮。
4. **双标签页 409**：版本冲突已由 API 与编辑保存路径处理，但未写 Playwright 双标签页用例。
5. **上传进度/取消**：已补失败场景与重试，但未做逐文件进度条和取消。
6. **1280 以下折叠**：CSS 已折叠三栏；未做截图与键盘全流程测试。
7. **共享 Mock 无租户隔离**：多人共用一个 Mock 实例时 Reset 会影响彼此，已知限制。
8. **保存状态**：以“有未保存修改”标签 + 成功提示呈现，未实现逐字段“保存中/已保存/保存失败”指示。
9. **图标仍会请求 api.iconify.design**（上游 Vben 图标机制），离线环境部分图标缺失。
10. **B 组交互仍待补**：报告“痛点→功能→价值”映射展示、功能 reviewStatus、痛点成本/传播潜力、证据反向引用与来源预览；列表“最近编辑/我的/已归档”tabs、封面、多平台裁切提示；业务 401 跳登录；项目卡键盘打开、动画降级、图片 lazy-load；演示探索树。
11. **M1 未覆盖**：真实 SSE/SignalR、分片上传、真实权限安全、账务与视频生成（属于后续阶段）。
